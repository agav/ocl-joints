2-panel connectors

Face component goes into the front/back face of a panel. Edge component goes into the edge of the other panel. In the tool, Left/Right select the row. "Learned" is the turn of the last turned joint (edge/face, 90° steps).

3-panel connectors

Face component is a through hole in the central panel. Edge component goes into the edges of both other panels. In the tool, Up/Down select the row.

Library folders

If the model has no component with the name, the tool loads <name>.skp from these folders (subfolders too). One folder per line.
